# Python CI Pipeline Project 🚀

This project demonstrates a **CI pipeline for a Python application** using GitHub Actions.

## 🔧 Technologies Used

- Python
- GitHub Actions
- Pytest
- Flake8

## ⚙️ CI Pipeline

The CI pipeline automatically runs when code is pushed to the repository.

Steps in the pipeline:

1. Checkout source code
2. Setup Python environment
3. Install dependencies
4. Run lint checks
5. Run automated tests
